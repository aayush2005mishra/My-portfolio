# Aayush Kumar Mishra — Developer Portfolio

A cinematic black-and-red personal portfolio for **Aayush Kumar Mishra**, B.Tech CSE (2023–2027), focused on Python, AI/ML and automation. Open to internships and entry-level roles in Software Development and AI/ML.

![Portfolio preview](assets/preview.png)

## Highlights
- Cinematic hero with neon glow, typewriter titles and 3D-tilt portrait
- Interactive red particle network that reacts to the cursor
- Animated developer terminal and AI technology orbit
- Animated project previews (illustrative) for RAG-Chat and Growing Sectors Analysis
- Scroll-triggered reveals, text-scramble headings, magnetic buttons, cursor spotlight
- Smooth eased navigation with scroll-spy
- Responsive, with touch-device fallbacks and `prefers-reduced-motion` support

## Featured projects
- **RAG-Chat** — document-based AI chatbot using a retrieve-then-generate architecture (Python, Streamlit, LLM, RAG)
- **Growing Sectors Analysis** — India employment forecast on PLFS (MoSPI) data across 12+ industries (Python, Pandas, SQL, Scikit-learn, Plotly)

## Tech
Single-file site: HTML, CSS and vanilla JavaScript. No build step, no dependencies.

## Run locally
Open `index.html` in any modern browser.

## Deploy (GitHub Pages)
1. Push this repository to GitHub.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
